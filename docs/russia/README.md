# 俄罗斯（Russia）

## 国家识别

俄罗斯最明显的特征：

* 西里尔字母（俄文）
* 蓝底白字路牌
* 白色路杆底部刷黑漆
* 白底黑字车牌

---

## 东西俄罗斯判断

### 西俄罗斯

特点：

* 人口密集
* 农田较多
* 道路质量较好
* 城镇分布密集

代表地区：

* 莫斯科
* 圣彼得堡
* 下诺夫哥罗德

### 东俄罗斯

特点：

* 森林覆盖率高
* 人口稀少
* 公路笔直且漫长

代表地区：

* 伊尔库茨克
* 雅库茨克
* 海参崴

---

## 常见地形

### 西伯利亚

* 大量针叶林
* 白桦树林
* 地势平缓

### 远东地区

* 山地较多
* 日本进口车常见

### 南部地区

* 草原景观
* 树木较少

## 新手必记

1. 先确认是否为俄文。
2. 观察森林还是草原。
3. 判断东西俄罗斯。
4. 留意城市名称和方向牌。
